# Reboot 0.5.2 verification

## Playback

The engine tests exercise Mono pedal release, Poly fallback at a hardware pitch boundary, Double, master tuning, and edits to a running arpeggio. They also cover a chord sharing a single fallback channel. If a bend brings an initially unplayable A0 into range while A2 holds the only available channel, A2 keeps sounding. Releasing A2 lets the waiting A0 play. Switching controls for an inactive cartridge leaves its saved configuration available for the next board change.

A trace of 128 disk master-volume writes showed that the old 32-entry queue discarded intermediate RC filter settings. At 384 kHz the same bus writes had a peak output difference of 0.00669 when rendered in blocks of 1 and 256. The new schedule keeps the last setting for each sample while preserving each DAC edge at its original chip cycle. The two renders now match, also at 48, 96 and 192 kHz.

For the factory demos, the 0.5.1 reference renderer reproduced all eight committed WAVs byte for byte. Square Lead and Disk Organ remain identical. In the other six, the new level-trim ramp changes part of the first 7.31 ms. All subsequent samples match the reference. The same sequence of trim changes now produces identical samples at callback sizes of 1, 16, 64 and 256.

## Performance measurements

Native tests used an Apple M1 Max, Apple Clang 21, 48 kHz, 64-frame callbacks and all eight factory MIDI phrases followed by a held-chord and sustain-pedal sequence. Timings exclude initialization and file output. Each pair used the same compiler flags, with FP contraction disabled, and ran in alternating order. The table reports calling-thread CPU time. Wall time was recorded separately. These are measurements of the native engine on this machine.

| Oversampling | 0.5.1 µs per callback | 0.5.2 µs per callback | CPU reduction |
| --- | ---: | ---: | ---: |
| 1× | 4.26 | 2.87 | 32.6% |
| 2× | 6.01 | 4.05 | 32.6% |
| 4× | 10.25 | 6.52 | 36.4% |
| 8× | 18.72 | 11.95 | 36.1% |
| All settings | 9.78 | 6.38 | 34.8% |

Mean elapsed callback time fell by 16.2% on the shared machine. With the playback fixes applied to both engines, all 88 stereo renders matched byte for byte (553,608,640 bytes). The comparisons used 64-frame blocks at 48 kHz, 256 at 44.1 kHz and 37 at 96 kHz. [Timings and render hashes](0.5.2-cpu.json)

The original and optimized disk-chip models also emitted the same DAC values on the same chip cycles across six seeded register traces. The traces switch between fixed gain and timed envelopes, exercise the modulator, and split the same timeline at different block sizes.

## Initialization

Building the 497-point cartridge transfer curve once per engine and preparing the revision-specific filter coefficients reduced engine preparation time from about 81 µs to 9.4 µs on the same machine. Repeated board resets use those coefficients directly. Tests comparing initialization and reset output across five sample rates and four oversampling settings produced 11,264,000 identical bytes.
